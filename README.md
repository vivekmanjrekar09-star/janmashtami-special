# 🪈 Janmashtami Dahi Handi Animation

An interactive web animation created for Janmashtami featuring custom SVG flute cursors, pot-shattering particle effects, and sound cues.

🎮 YOU CAN TRY IT HERE **[Live Demo](https://vivekmanjrekar09-star.github.io/janmashtami-special/)** 

## ✨ Features
- Custom Krishna coconut SVG cursor.
- Dynamic pot shattering & curd dropping CSS keyframe animations.
- Sound effects triggered on click (Pot break & go go govinda track).
- Responsive card reveal upon completion.

## 🛠️ Built With
- **HTML5**
- **CSS3** (Animations & Clip-path)
- **JavaScript** (DOM Manipulation & Audio API)
